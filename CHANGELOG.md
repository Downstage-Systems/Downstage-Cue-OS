# Changelog

## 0.186.3 (2026-10-28)

The Cue Mini's first release. All lights: steadier CueLink, and a light no longer installs a firmware file older than its own. The Cue Lite: a short welcome on its first link, a dim Downstage mark while it sleeps, Factory Reset in its menu, and gentler battery charging.

## 0.146.0 (2026-10-20)

The first public release. A light now takes only firmware made for it, and its page tells you when a newer one is out and installs it in one tap. Also: the round Cue runs its own timer when there is no One, three power-ons in a row reset a light to new, and a cleaner web page.
